## 帰宅後に見る順番（今日のチェックリスト）

**準備（10分）**

- [ ] ワンタイムパスワード設定、無料テレポ先を拠点の街に
- [ ] モンクのギアセット登録、Lv30・35のモンククエスト受注確認
- [ ] キャラクター設定をサーバーにバックアップ
- [ ] 設定まとめの「今日やる3つ」（バトルログ別タブ、ターゲットHP数値、食事）

**白魔道士へ**

- [ ] グリダニアで幻術士取得、Lv15まで（クラスクエ1・5・10・15）
- [ ] 初心者の館でヒーラー課題を全部、ブランドニューリング取得
- [ ] 死者の宮殿＋ルーレットでLv30、ジョブクエで白魔道士
- [ ] ギアセット登録→1番へ移動、HUD1番、切替マクロ
- [ ] マクロ集の挨拶・マウント・LB・マウスオーバー（ケアル）を作成

**イベント・寄り道**

- [ ] ゴールドソーサー解放（ウルダハ「いざ、魅惑の遊技場へ」）
- [ ] Fall Guys（ブランダーヴィル）解放、MGF集め開始
- [ ] ドマ式麻雀：NPC戦1局でUI確認→マッチング1〜2局
- [ ] モグコレ：旅のモーグリでガイドブック受け取り、対象コンテンツ確認
- [ ] 10/15〜 守護天節（グリダニア旧市街）

**リテイナー（Lv17のクエスト後）**

- [ ] Alpha-Zulu（戦闘＝モンク）を雇用、「探索」を依頼
- [ ] Charlie-Zulu・Foxtrot-Zulu は採集職を触ってから
- [ ] 15文字の名前（例：Charlie-Whiskey）で文字数上限を確認、pii付きが通るかも試す

## チャットで話したが文書にない話題

必要になったら聞き直せば再説明する。文書化したいものがあれば言えば追加する。

**ヒーラー・ジョブ**

- 白魔 vs 学者の比較（汎用性は白魔、選択肢の広さは学者）
- ヒーラーのダンジョンでの立ち回り（タンクを見る、回避優先、全体攻撃に全体回復、余りで攻撃、DoT）
- 白魔道士 Lv1〜50 のスキルと使い方（ベニゾン・ホーリー・アサイズ・迅速魔→レイズ）
- モンクの基本と、サブとして残す理由（ソロ周回、全ジョブカンストの1本目）
- 高難度の種類（極・零式・絶・幻・アライアンス）と入る順番
- 制限解除とソロ周回（マウント・ミラプリ集め、2拡張下が目安）
- 青魔道士、魔獣使い（リミテッドジョブ。どちらも後回し）

**システム・運用**

- リテイナーの倉庫分類（装備＝Alpha、素材＝Charlie、その他＝Foxtrot）、「同じアイテムをまとめて預ける」、ベンチャー品はリテイナーの所持品に入る
- 追加リテイナーはアカウント全キャラに適用、アプリ込みで3体
- 装備の修理・マテリア・染色、捨てる前の順番（ドレッサー→マテリア化→軍票納品→売る）
- 装備更新の流れ（Lv50で詩学、各拡張の最後も詩学）
- ギアセットは同ジョブ複数も可だが初心者は1ジョブ1セット
- アカウント周り（OTP、契約コース、モグステ、休止時の注意）
- グラフィック設定（DoF・ブラーオフ、FPS上限、他人のエフェクト簡易表示）
- ロードストーン、使っていい外部サイト、外部ツールは禁止
- BGMは家の中でしか選べない。要望は昔からあるが未実装
- 要望から実装された例（フェイス、抽選ハウジング、ドレッサー拡張、ブラックリスト強化など）

**コンテンツ**

- 死者の宮殿（幻術士レベリングの主戦場）、風脈、ジョブクエ・ロールクエ（漆黒以降はメインの前提）
- ゴールドソーサーとMGP（ファッションチェック週1、くじ、G.A.T.E.、トリプルトライアド、ドマ式麻雀）
- グランドカンパニー・軍票・冒険者小隊（軍曹で解放、経験値バフ）
- 友好部族（Lv41〜）、FATE（漆黒以降はバイカラージェム、特殊FATE）、探検手帳、モブハント
- 宝の地図、無人島開拓、イシュガルド復興、コスモエクスプローラー、フィールド型コンテンツ（エウレカ・ボズヤ・クレセントアイル）
- オーシャンフィッシング（漁師Lv1で参加可、モグコレ対象）
- コンテンツサポーター（初見はサポーター、2回目から野良）
- ヒルディブランド、FF他作品とのつながり（クリスタルタワー＝FF3、オメガ＝ケフカ、FF7レイドは8.01）
- ミラプリ・グルポ・ポートレート、マウントとライディングマップ、オーケストリオン

**コミュニティ**

- 重宝されるプレイヤーになるには（挨拶・謝る・抜けない・タンクを死なせない）
- FCでの立ち回り、フレンド・LS・PT募集・DC移動、メンター制度
- 配信・SNSのルール（人を映さない、晒さない、ネタバレを隠す）
- 用語集、コミュニティ文化とネタ、FF14の歴史（旧版→メテオ→新生）、今の話題
- 初心者がやりがちな失敗10、キャラクリ・種族・ファンタジア（新生クリアで無料1個）
- 新生ストーリーの楽しみ方（ネタバレなし）、日課・週課（15分版と1時間版）、食事と薬
- 進行の時間目安（新生今週、黄金まで2〜3ヶ月、全ジョブ1年、実績は年単位）
- AION2との比較（FF14メイン、AION2は気分転換）

**8.0関連**
