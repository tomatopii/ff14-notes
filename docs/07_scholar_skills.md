# FF14 学者（Scholar）アクション・特性リファレンス（パッチ7.5時点 / 2026年10月調査）

- 数値（威力・回復力・リキャスト等）は公式ジョブガイド（日本語版）の記載をそのまま転記。公式ガイドは「Lv100時点で表示される内容」を掲載しているため、低レベル帯での威力は特性の記述から逆算できる範囲のみ補記し、不明なものは「要確認」とした。
- 「種類」の凡例：**魔法**＝GCD（グローバルクールダウンに乗る）／**アビリティ**＝oGCD（GCDの合間に挟む）／**ペット**＝フェアリー・セラフィムが実行するアクション（ホットバー登録不可）。
- 英語名は公式英語版ジョブガイド（NA）より。
- 使い方・頻度の記述は The Balance（Patch 7.4 対応）、game8（Lv100スキル回し、最終更新 2025.11.21）、note「学者歴2ヶ月が考える学者の歩き方（7.05）」、Icy Veins（7.55）を出典とし、どのガイドの主張かを各所で明記した。
- パッチ7.5でのジョブ変更：The Balance の Job Changes ページには 7.4 の「蠱毒法 DoT威力 80→85」のみ記載。7.5 固有の学者変更は本調査では確認できなかった（**要確認**：公式 7.5 パッチノート）。

### 5-2. Lv100 単体スキル回し（開幕〜2分ループ）

**The Balance「Early Refresh, 2nd GCD Chain」（Dawntrail 7.0 画像、7.4ページに掲載）**

- −1.5秒：極炎法（プリキャスト）
- GCD1：蠱毒法 →（薬）→ 転化（※画像上は「Dissipation」表記。Openersページは「エーテルフローと転化は入れ替え可」としており、どちらを先にするかは下記トレードオフ参照）
- GCD2：極炎法
- GCD3：極炎法 → 連環計
- GCD4：極炎法 → エナジードレイン
- GCD5：極炎法 → エナジードレイン
- GCD6：極炎法 → エナジードレイン
- GCD7：極炎法 → エーテルフロー（画像ラベルは「Dissipact」だが、転化は180秒リキャストのため2回目はエーテルフローと解釈。**要確認**）
- GCD8：極炎法 → 埋伏の毒
- GCD9：極炎法 → エナジードレイン
- GCD10：極炎法 → エナジードレイン
- GCD11：蠱毒法 → エナジードレイン（バフ終了際の早期更新）

転化先行のトレードオフ（The Balance Openers）：フェアリーが約15秒早く戻る／エーテルフローのMP2000が遅れて来るので溢れにくい／2分時に6回エナジードレインのバフ窓が揃う。欠点：戦闘全体でエーテルフロー使用回数を1回失うリスク、エーテルフローの戻りタイミングが変わりヒール計画に影響。

**game8「転化回し」（Lv100、最終更新2025.11.21）**：
極炎法 → 蠱毒法 → エーテルフロー → 極炎法 → 極炎法 → 連環計 → 極炎法 → エナジードレイン → 極炎法 → エナジードレイン → 極炎法 → エナジードレイン → 極炎法 → 転化 → 極炎法 → 埋伏の毒 → 極炎法 → エナジードレイン → 極炎法 → エナジードレイン。
（開幕の極炎法後に薬。回復が必要ならエナジードレインをヒールスキルに置き換える。妖精を早く戻したい時は3番目のエーテルフローと14番目の転化を入れ替える。）

**2分ループの骨組み（note・The Balance Basic Guide の記述を統合）**
- 連環計（120秒）を偶数分の基準にし、エーテルフロー（60秒）を毎分リキャスト即押し。両者にその他の長リキャストを割り振る。
- 転化（180秒）は2分周期と噛み合わないため、火力重視なら毎回リキャスト即（ただし、その後30秒フェアリー不在で問題ない場面のみ）。
- 連環計直後に埋伏の毒。エーテルフロー分のエナジードレインはバフ内に寄せる。
- 蠱毒法は30秒毎。バフ終了際に早期更新してバフ内DoTを1回増やす（The Balance Openers）。
- 余った移動時間は蠱毒法（無詠唱）のタイミングや極炎法後の約1秒＋スライドキャスト約0.5秒で処理し、ルインラは最後の手段（The Balance Basic Guide）。

### 5-3. 範囲（複数敵）時の回し

- 2〜4体：全ての敵に蠱毒法を撒いてから裂陣法を連打（The Balance Skills Overview）。5体以上：DoTは省略して裂陣法のみ。
- Icy Veins（7.55）：バイオラは2体まで、蠱毒法は3〜4体まで維持。裂陣法（破陣法）は2体以上で使用。
- The Balance Leveling Guide：破陣法はLv46〜で2体以上（Lv64〜は単体では不使用）、Lv72〜は5体以上、Lv82〜（裂陣法）は4体以上、Lv94〜は5体以上、と閾値を記述（版によって揺れあり、要確認）。
- 雑魚でも連環計→埋伏の毒を使う。埋伏の毒は群れの中央の敵を対象にして全員にDoTを乗せる（The Balance）。パックが15秒以上生きるなら連環計を使う（Icy Veins）。
- 裂陣法は無詠唱なのでoGCDを2つ挟める。
- 雑魚道中のヒール：エーテルフロー系（野戦治療の陣、不撓不屈）、フェアリー系（光の囁き、フェイブレッシング、エーテルパクト）、プルごとにタンクへ鼓舞激励の策（The Balance Leveling Guide）。

### 5-4. ヒールの優先順位

The Balance Basic Guide（7.4）：**無償回復（フェアリー系・リキャスト系）＞エーテルフロー回復＞GCD回復**。
相対コスト：無償回復 0威力 ／ エーテルフロー回復 −100威力（エナジードレイン1回分） ／ GCD回復 −310威力（極炎法1回分）。

具体的な順序（The Balance Skills Overview の記述を再構成）：
1. フェアリー・リキャストのみのoGCD：光の囁き／フェイブレッシング／フェイイルミネーション／エーテルパクト／コンソレイション／疾風怒濤の計／生命回生法
2. エーテルフロー消費のoGCD：野戦治療の陣（Lv78以降は最優先のフロー回復。PTが留まる場面）＞深謀遠慮の策（タンク事前回復。Lv62〜は生命活性法より優先）＞不撓不屈の策（秘策との組み合わせ、または陣が使えない時）＞生命活性法（深謀遠慮・陣が使えない時のみ）
3. GCD回復（最後の手段）：鼓舞激励の策（タンクバスター、または展開戦術用）／意気軒昂の策（コンソレイション不可時の範囲バリア）／フィジク（MP枯渇時のみ）／応急戦術付きGCD（HP全回復チェックや、コヒーラーにもoGCDが無い時のみ）

例外：後のギミックのためにリソースを温存する場合、野戦治療の陣や展開鼓舞のような軽減がギミックを大幅に楽にする場合（The Balance）。
note（7.05）：学者は見てから動くと間に合わないため、全体攻撃ごとに事前にバリアを仕込む。MPは蘇生（2400）とミスのカバー用に残す。学者は燃費が悪く、特にセラフィズム中はMPが急減する。
