Fall Guys（ブランダーヴィル）

必要 6,120 MGF（消耗品除く）。カララント3色も揃えるなら＋2,250で 8,370。

  • 解放：ゴールドソーサー X:4.8 Y:6.1 のレウェナから「つかめ、勝利のクラウン！」（Lv15、サブクエ「いざ、魅惑の遊技場へ」クリア）
  • 会場：ワンダースクウェアのゲートキーパー、または各都市の「ブランダーヴィル案内人」
  • 交換：会場内の報酬交換NPC

モグモグ★コレクション ～天文に至る路 Part1～

必要 希少トームストーン：天文1章 723個 ＋ ウォロン・ホルン交換手形 10枚。カード3枚（27個分）は暁月・黄金のクエストが条件なので、現実ラインは 696個。

  • 対象コンテンツはだいじなもの「モグモグガイドブック」で確認（旅のモーグリから受け取る）。コンテンツファインダーでモーグリアイコン付きが対象
  • 交換：旅のモーグリ（リムサ下甲板層 / グリダニア新市街 / ウルダハ ナル回廊）。交換はパッチ8.1まで可能、ガイドブックからの報酬受け取りは8.05まで
  • 手形：ウィークリープチモグチャレンジで週1枚、モグモグチャレンジ（期間中1回）づ5枚。残り2週なので今から最大7枚。手形もホルンも Part2 に持ち越せるので、Part1 で足りなくても問題なし
  • 冒険者小隊・コンテンツサポーターでは入手不可。制限解除はレベルシンク併時のみ可

FF15コラボ ～英雄への夜想曲～

必要 230,000 MGP ＋ 未知なる魔導部品 6個。受注条件が Lv50 ＋ メインクエスト「究極幻想アルテマウェポン」完了なので、今回（10/13まで）は見送り。復刻は何度も来ている。

  • 受注：ウルダハ ナル回廊 X:8.5 Y:9.7 キピ・ジャッキヤ「黒尽くめの青年」
  • 魔導部品：1つ目のクエスト中の中央ザナラーンFATEで入手
  • 交換：ゴールドソーサー「ガーロンド社の販売員」（マウント・ヘア・カード）、三国＋ブラックブラッシュ「ガーロンド社員」（オーケストリオン譜）
  • ボス戦で負けると Easy / Very Easy が選べる
