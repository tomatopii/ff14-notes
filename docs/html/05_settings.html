FF14 設定・ギアセット・QoLまとめ

Oct 8, 2026 · @tomatopii

マウス＋キーボード、12ボタンマウス、ヒーラーメイン前提。マクロの本文は「FF14 マクロ集」を参照。

ギアセットの運用ルール

ギアセット＝ジョブごとの装備一式を保存したスロット。切り替えるとジョブも装備も一緒に変わる。リストは空き番号を作れないので、番号固定ではなく並び順で管理する。

並び順（右クリック→上に移動／下に移動で調整）

  1. ヒーラー（白・学・占・賢）← 1番は常にメイン
  2. タンク（ナ・戦・暗・ガ）
  3. 近接DPS
  4. 遠隔DPS
  5. キャスター
  6. 青魔道士
  7. クラフター（木工→鍛冶→甲冑→彫金→革→裁縫→錬金→調理）
  8. ギャザラー（採掘→園芸→漁師）

名前：ジョブ名そのまま。同ジョブで複数作るときだけ「白魔道士 ミラプリ夏」のように用途を後ろに。初心者のうちは1ジョブ1セット。

更新ルール

  • 装備を変えたら必ず「現在の装備で更新」。忘れると次の切替で古い装備に戻る
  • 「おまかせ装備」→「更新」で、IL最大の状態を1クリック保存
  • アクセサリは共有できる（白魔と学者で同じ癒し系アクセを両方に登録してOK）
  • ソウルクリスタル（ジョブ）もギアセットに含まれる。Lv30でジョブになったら登録し直す

マクロは番号ではなく名前で

/macroicon "白魔道士" gearset
/macroerror off
/gearset change "白魔道士"

番号指定だと並びを動かしたときにマクロが壊れる。名前指定なら動かしても平気。

HUDはジョブではなくパーティの人数で切り替える。ジョブ切替マクロには /hudlayout を入れない。

HUDの基本：ホットバーは画面中央下、パーティリストは左寄り中央、自分のHP・ターゲット情報・キャストバーは中央寄りに集める。敵の詠唱バーはターゲット情報を分割表示にして大きく。ホットバーのサイズは120%以上。

12ボタンマウスの層（押す頻度で分ける）

層 中身
そのまま GCD（コンボ、範囲、常時回すもの）
Shift 毎ループで差し込む oGCD（短CDのバフ・デバフ）
Alt たまに使うもの（2分以上のCD、防御、蘇生、LB、スプリント）
Ctrl 戦闘外・緊急（ポーション、マウント、テレポ）

「Shift＝攻撃を強くする、Alt＝身を守る／稀、Ctrl＝戦闘外」と覚える。押しやすさは「なし > Shift（小指を下にずらすだけ）> Alt（親指）> Ctrl（小指を一番下まで伸ばす、移動中に押しにくい）」の順なので、頻度の高い層からこの順に割り当てる。48枠は使い切れないので、まずは12×3＝36で始める。

キー割り当て（Razer Naga V2 HyperSpeed）

マウスボタン Synapseの設定 FF14 ホットバー1 ホットバー2 ホットバー3 ホットバー4
1〜12 キーボード機能→機能→F1〜F12 F1〜F12 Shift+F1〜F12 Alt+F1〜F12 Ctrl+F1〜F12（F10は空ける：IME予約）
  • FF14の初期設定では F1〜F8 が「パーティメンバーをターゲット」。ホットバーに登録するときに上書きする（マウスオーバーとパーティリストクリックで代用）
  • Alt+F4 は FF14 側で無効化されていてゲームは終了しない（公式フォーラム）。ホットバーに割り当ててよい
  • テンキーを使う場合は Shift+テンキーが NumLock 解除扱い（Home/End/矢印）になる。Fキーにしたのはこれを避けるため
  • Synapse に F13〜F24 はない
  • Ctrl+F10 と Ctrl+F7 は Microsoft IME の予約キー（IMEメニュー・単語登録）。メニューが開いて操作が止まる。Ctrl層の7・10は空けるか、IME設定のキー割り当てで無効化。Shift+F10（Windowsの右クリックメニュー）も要確認
  • NVIDIA オーバーレイの既定ホットキー（Alt+F1/F2/F3/F9/F10/F12）と衝突する。オーバーレイをオフにするかホットキーを変更

ホットバーの置き方

  • マウスの3列×4段とホットバーの見た目を同じ3×4に揃える（ホットバー設定でレイアウト変更）。親指の位置と画面の位置が一致する
  • よく押すものは親指のホームポジション付近（真ん中段）、端のボタンは長CDに
  • マウス側ソフトで12ボタンをテンキーやF1〜F12に割り当て、ゲーム内でそれをホットバーにバインドすると安定
  • キーボードの1〜5は戦闘外バー（挨拶マクロ、マウント、テレポ、ジョブ切替）

操作系で最初にやる設定

  • 移動設定→「レガシー」
  • 「スキル使用時にターゲット方向へ自動で向く」オン
  • カメラ最大距離を最大に

ホットバー配置（学者・Lv100最終形）

層＝頻度、層内＝用途。未習得のスキルの席は空けておき、習得したらそこに入れる。表はマウスを握った時の見た目（4列×3段：上段 3-6-9-12、中段 2-5-8-11、下段 1-4-7-10）。(mo)＝マウスオーバーマクロ。バイオ・ルイン・破陣法はレベルで同じボタンが自動強化される（バイオ→バイオラ→蠰毒法、ルイン→気炎法→魔炎法→死炎法→極炎法、破陣法→裂陣法）。

持ち方：1〜9は親指の指先（第一関節を軽く曲げる）、10〜12は親指の付け根で押す。指先の定位置は5・8。付け根で押す10〜12は精度が粗いので、誤爆しても痛くないもの（長リキャストのバフ・リジェネ・稀なもの）を置き、LBは指先側に。

QoL設定チェックリスト

戦闘で効く

  • ターゲットのHPを数値表示（キャラ設定→UI設定→ターゲット情報）
  • ターゲットサークルの表示をオン（ボスの正面・背面が分かる）
  • 敵の詠唱バーを分割表示にして中央寄りに大きく
  • カメラ最大距離を最大に
  • ネームプレート：他PCは「PTメンバーのみ」
  • 他プレイヤーの表示数を減らす（重いとき）

日常で効く

  • ログイン時のサーバーをメインキャラに固定
  • チャットタブを分ける：バトルログを別タブへ
  • ミニマップの回転オフ、マップの透過度を上げる
  • アイテム入手時に自動整理（または /isort マクロ）
  • 装備画面で「装備可能なものだけ表示」
  • エーテライトお気に入り登録（3件＋アプリで1件）
  • マウントルーレット＋飛行中の自動降下オン
  • ロット設定を「おまかせロット」に
  • 宿屋ベッドでログアウト（休息ボーナス）

知ってると得

  • キャラクター設定をサーバーにバックアップ（システム→キャラクター設定のバックアップ）。PCを変えてもHUD・キーバインド・マクロが戻る
  • 食事は何でも経験値＋3%。安い料理を常食（30分）
  • 冒険者小隊（GC Lv20〜）の経験値アップを取る（10〜15%）
  • /isearch アイテム名 でリテイナー含め全倉庫を横断検索
  • Shift＋右クリックで装備比較、Ctrl＋右クリックでチャットにリンク
  • マクロは個人100＋アカウント共通100。挨拶やマウントは共通側に
